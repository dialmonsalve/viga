# create-viga

Creates a new [viga](https://vigajs.dev) project.

```sh
pnpm create viga my-app
```

It also works with `npm create viga@latest my-app`, `yarn create viga my-app` and `bun create viga my-app`. Use `--schema valibot` or `--schema none` to change the validation library, which is Zod by default.
