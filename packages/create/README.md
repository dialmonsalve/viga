# @vigajs/create

Creates a new [viga](https://vigajs.dev) project.

```sh
pnpm create @vigajs my-app
```

It also works with `npm create @vigajs@latest my-app`, `yarn create @vigajs my-app` and `bunx @vigajs/create my-app`. Use `--schema valibot` or `--schema none` to change the validation library, which is Zod by default.
